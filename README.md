# Christoffel's Kitchen - Mobile Menu App

## Introduction

This mobile application was developed for Christoffel, a private chef who creates personalized culinary experiences for his clients. The app serves as a dynamic digital menu that allows Christoffel to easily update his offerings while providing clients with an elegant way to browse his latest creations. Built with React Native and TypeScript, it ensures a seamless experience across both iOS and Android platforms.
